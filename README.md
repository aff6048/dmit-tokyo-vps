## 东京节点通常被用在三种场景，选型逻辑完全不同

- **访客主要在中国大陆**，晚高峰打开网页不能转圈。这类用户唯一该看的是回程线路，机房在东京只是加分项。
- **需要日本原生 IP**，做区域业务、流媒体、注册环境、亚太落地点。这类更在意 IP 段质量和机房属性，不在极限延迟。
- **业务面向日本本地或全球**，东京只是亚太互联的一个跳板。这类看的是国际带宽和流量单价，回国质量完全是浪费预算。

## 动手之前，先搞清楚「流量超了会怎样」这类细节

多数人比价格的时候忽略这几项，等用量跑起来才发现问题：

1. **超量策略不一样**。Pro 系列流量用完直接暂停，等下个计费周期重置才恢复；Tier 1 系列超量后不停机，改成限速继续跑（WEE 档限到 50Mbps，多数档位限到 100–200Mbps 且不限量）。前者适合有预算做监控的业务，后者适合下载、备份这类可以把速度慢下来的活。
2. **带宽标的是端口速率**，不是任何时间都能跑满的保证值。1Gbps 端口和「稳定 1Gbps」是两回事。
3. **延迟数字只能做参考**。第三方测评给出的数值大致是：东京 Pro 到中国大陆 50–80ms，香港节点 20–50ms。你自己的宽带和路由会影响结果，更靠谱的做法是先 ping 一下测试 IP：Pro 段是 154.12.190.32，Tier 1 段是 154.31.112.5，官方还提供了 Looking Glass 页面可以查回程路由。

## 缺货是常态，购买节奏可以这样安排

Pro 线的 TINY 和 STARTER 长期处在库存紧张状态，官方客服的说法是补货来自释放出来的 IP 资源，量不大，短期也不会有大规模放货。真想上车，节奏大致是：

1. 先看库存，有货就别拖，等一周未必还有
2. 拿低配先跑一个计费周期，用测试 IP 之外的自家网络验证延迟和丢包
3. 确认线路对得上需求，再决定要不要升档或转年付

先看货再决定预算，比先定预算干等补货要实际得多。

## 几个被问得最多的问题

**流量跑超会直接停机吗？**
看系列。Pro 超量暂停到下个周期重置；T1 超量限速不停机，这也是 T1 敢给 16TB、32TB 这种大流量的原因。

**东京和香港怎么选？**
香港延迟更低（第三方测评大致 20–50ms），但同档配置价格明显更高、低价机型经常售空。东京是延迟和成本之间比较折中的一个点，50–80ms 对绝大多数站点足够。

**能不能装 Windows？**
第三方测评提到 4GB 内存以上的档位支持 Windows，这个说法我无法在官方页面直接核实，真要用 Windows 建议下单前问一次客服。

**要买多长的周期？**
不确定就先月付。DMIT 月付基本不参与大额折扣，但也意味着你不用为试用付一年的钱。
